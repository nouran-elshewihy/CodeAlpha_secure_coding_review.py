 Secure Coding & Review Simulation

A simple Python script to practice secure coding, input validation, and error handling.

## What this script does:

- **Input Validation:** Uses regex to check user input (like email patterns) and block invalid or malicious data.
- **Error Handling:** Uses try-except blocks to catch runtime errors safely without crashing the app.
- **Logging:** Automatically saves security events and logs into `security_report.log`.

## Files:
- `secure_coding_review.py`
- `security_report.log`
